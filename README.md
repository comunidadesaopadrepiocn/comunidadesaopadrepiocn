## ✨ Sobre a comunidade

A Comunidade São Padre Pio busca utilizar a tecnologia para aproximar as pessoas, facilitar o acesso à Palavra de Deus e apoiar as iniciativas da comunidade.

## 💻 Nossos projetos

### 📖 Salmo do Dia

Um projeto desenvolvido para facilitar o acesso diário à Palavra de Deus.

Por meio de um QR Code, qualquer pessoa pode acessar uma página com o salmo do dia, de forma simples e rápida.
