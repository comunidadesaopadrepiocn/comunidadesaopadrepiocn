# ✝️ Comunidade São Padre Pio

**Seja bem-vindo(a) ao espaço digital da Comunidade São Padre Pio!**

Este espaço reúne os projetos e as soluções tecnológicas desenvolvidos para apoiar as atividades da nossa comunidade, utilizando a tecnologia como ferramenta de evangelização, comunicação e organização.

---

## ✨ Sobre a comunidade

A Comunidade São Padre Pio busca utilizar a tecnologia para aproximar as pessoas, facilitar o acesso à Palavra de Deus e apoiar as iniciativas da comunidade.

## 💻 Nossos projetos

### 📖 Salmo do Dia

Um projeto desenvolvido para facilitar o acesso diário à Palavra de Deus.

Por meio de um QR Code, qualquer pessoa pode acessar uma página com o salmo do dia, de forma simples e rápida.

**[📖 ACESSE O SALMO DO DIA](https://comunidadesaopadrepiocn.github.io/salmo-do-dia)**
